# Network Checker Pro 🔥

ابزار پیشرفته بررسی شبکه + اسکنر IP تمیز + تولید کانفیگ

Advanced Network Scanner, Clean IP Scanner & Config Generator

> ⚠️ **For authorized penetration testing only**

---

## ✨ Features | قابلیت‌ها

- Clean IP Scan (Cloudflare, Fastly, Gcore, Netlify)
- TCP Port Scanner (Multi-threaded)
- DNS Propagation Check
- Subdomain Scanner
- SNI Finder & Tester
- SSL/TLS Handshake Check
- HTTP/HTTPS Response Check
- Config Generator (VLESS, VMess, Reality)
- IP Shuffling & Mixing (Random, Interleave, Block)
- HTML Report (Persian/Farsi)
- Full Mixed Mode (All-in-One)
